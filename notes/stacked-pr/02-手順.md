# Stacked PR の手順

## 準備（1 回だけ）

```
gh extension install github/gh-stack
```

GitHub CLI は 2.90.0 以上が要る。

## 積む

1. `gh stack init <ブランチ名>` … 一番下の層のブランチを作って切り替わる
   - 宛先を main 以外にするときは `gh stack init --base develop <ブランチ名>`
   - 初回に「git rerere を有効にするか」と聞かれる。衝突の直し方を覚えて、次から自動で直す機能。設定はそのリポジトリの `.git/config` に入る
2. ファイルを書いて、いつもどおり `git add` → `git commit`
3. `gh stack add <ブランチ名>` … いまの層の上に次の層のブランチを作って切り替わる
4. 2 と 3 を層の数だけ繰り返す

## PR にする

- `gh stack view` … 全段のブランチ・PR・状態を一覧で見る
- `gh stack submit` … 全ブランチを push し、宛先を正しく付けた PR をまとめて作る
  - 画面が開き、PR ごとに題名・説明・下書きにするかを決めてから Ctrl+S で送る

## 直す・入れる

- `gh stack rebase` … 下の層を直したあと、上の層を付け直す
- `gh stack sync` … 手元をリモートに合わせる
- `gh stack merge` … スタックをマージする（GitHub の画面で一番上をマージしても同じく全段が入る）
