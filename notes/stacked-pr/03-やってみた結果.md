# Stacked PR をやってみた結果

このメモ自体を 3 段のスタックにして試した（01 仕組み → 02 手順 → 03 このファイル）。

## 分かったこと

- `gh stack init` の初回に git rerere を有効にするか聞かれる。Yes にすると、そのリポジトリの `.git/config` にだけ入る（`git config --show-origin` で確認）
- `gh stack add` はブランチを作って切り替えるだけ。コミットは自分で `git add` → `git commit` する（`-Am` を付ければまとめてできる）
- `gh stack view` で全段が縦に並んで見える。コミットの無い段は、ひとつ下の段と同じコミットを指す

## これから確かめること

- `gh stack submit` で PR が 3 本でき、宛先がひとつ下の段のブランチになるか
- PR の画面に段の番号とスタックマップが出るか
- 一番上をマージすると 3 本まとめて main に入るか
