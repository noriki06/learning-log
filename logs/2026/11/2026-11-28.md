## 今日のニュース

- **Anthropic、Claude の API を Python から Rust に書き直したと公開**（11/25）
  API の中身を別の言語で作り直し、サービスを止めずに本番の通信と結果を突き合わせて確かめた。CPU の使用量は約 7 割減、最初の応答までの時間も約 2 割短くなったという。
  テストが通っても本番と同じ動きとは限らない、という実例。作り直しでは「本物の入出力で比べる」確かめ方が効く。
  https://www.anthropic.com/research/migrating-api-to-rust

- **カナダ政府、AI の計算資源を使う企業への補助を 10 億カナダドルに拡大**（11/26）
  既存の基金に 7 億カナダドルを足し、国内のデータセンターを使う中小企業の計算費用を支援する。累計で 89 社への支援が決まっている。
  AI を動かす計算資源（GPU など）の確保が、国の政策になっている流れが分かる。
  https://www.canada.ca/en/innovation-science-economic-development/news/2026/11/government-of-canada-boosts-the-ai-compute-access-fund-with-700-million-expansion.html
