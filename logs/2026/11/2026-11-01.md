## 今日のニュース

- **Cursor のマーケットプレイスで Claude Code 拡張機能の改ざん版が配布される**（10/30）
  10/29 に約 11 時間、Cursor 上の拡張機能 2.1.313 がすり替えられ、入れた PC に攻撃者の SSH 鍵（外から入れる合鍵）を仕込む作りになっていた。影響は最大 5,000 人。
  拡張機能を消すだけでは鍵が残るので、該当者は `~/.ssh/authorized_keys` に `svc-telemetry` という鍵がないか確認が要る。「公式の配布元から入れても安全とは限らない」事件。
  https://www.ox.security/blog/malicious-claude-code-extension-cursor-ssh-backdoor/

- **AI の学習に使わないでほしい意思を robots.txt で示す共通の書き方が提案される**（10/30）
  Anthropic の著者が IETF（インターネットの規格を決める団体）に草案を出し、`User-Agent: __usage_ai-training` の下に `Disallow: /` と書けば「学習に使わないで」と示せる案。まだ個人の草案で正式な規格ではない。
  OpenAI・Google・Microsoft・Anthropic が対応を表明したと報じられている。サイトを運営するなら、各社ごとに違う書き方をしなくて済むようになる方向。
  https://datatracker.ietf.org/doc/draft-kelley-aipref-training-preference-signal/

- **OpenAI の Python SDK 3.42.0 が公開**（10/31）
  エージェント向けに、長くなった会話の文脈を圧縮する設定（context compaction）、セッションの振り返りやツール設定、組織の外部キー管理などが追加された。
  長時間動くエージェントを作るとき、文脈の長さをどう抑えるかが SDK 側の機能として用意され始めている。
  https://github.com/openai/openai-python/releases/tag/v3.42.0
