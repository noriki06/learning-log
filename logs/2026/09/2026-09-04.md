## 今日学んだこと

> - 永続化は教材の 4 点セット（model / table / repository / package.scala）＋ reference.conf の 1 行
- DSN は conf の場所を指すパス。conf 無しでも実装・コンパイルは進む
- Play でも reference.conf は必要。消えるのは手組みの入口だけ
- deriveColumns は入れ子 case class を nullable 列に平坦化できる
- Slick が知らない型: JSON は circe、素の enum は MappedColumnType.base(_.code, valueOf)、trait は登録簿 fromCode
- DDL は DB 無しで query.schema.createStatements から確認できる
- DI に登録するのは Table / Repository だけ。モデルは値
