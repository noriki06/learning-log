## 今日のニュース

- **Linux カーネル 7.3 が正式リリース**（10/18）
  Linux の中核部分（カーネル）の新しい正式版 7.3 が公開された。kernel.org のトップで「Latest Release」として表示されている。
  すぐに手元の環境が変わるわけではなく、Ubuntu などの各ディストリビューションが数か月かけて取り込んでいく。サーバーを扱うなら「いま自分の環境のカーネルは何版か」を意識するきっかけになる。
  https://www.kernel.org/

- **Anthropic、NIST 楕円曲線の「種」の由来を Claude で解明**（10/16）
  HTTPS などで広く使われる暗号（楕円曲線 P-256 など）には、1990 年代から説明のつかない定数「seed」があった。Anthropic の研究チームが Claude に調べさせたところ、古い C 言語の乱数関数 `lrand48` を Unix 時刻で初期化した出力だったと判明した。
  暗号が破られたわけではなく、むしろ「裏口（バックドア）が仕込まれた可能性は低い」という結論。AI が過去のコードの癖を推理して謎を解いた例として読める。
  https://www.anthropic.com/research/ecdsa-curve-origins

- **DeepSeek、V4.1-Flash-1017 を公開。重みも公開、検索 API も提供開始**（10/17）
  中国の DeepSeek が高速モデルの更新版を出した。応答が短く速くなり、コーディングやエージェント（自律的に作業する AI）向けに最適化されている。モデルの重み（学習済みデータ）は Hugging Face などで公開されている。
  同時に、AI から呼べる Web 検索・取得 API を 1,000 回あたり 0.75 ドルで提供開始。自分のアプリに「AI が検索する」機能を安く組み込める選択肢が増えた。
  https://api-docs.deepseek.com/news/news261017
