## 今日のニュース

- **PHP に「外から任意のコードを実行される」重大な穴が 2 件、緊急修正版が公開**（10/21）
  Web サイトの裏側で広く使われている言語 PHP に、ログイン不要で攻撃できる深刻な脆弱性が 2 件見つかり、8.2〜8.5 系の修正版が出た。すでに攻撃に使われていたとの報告もある。
  設定での回避策は「緩和にはなるが安全にはならない」と公式が明言している。古い PHP を動かしているサーバーがあるなら、更新と全ワーカーの再起動が必要。「古いソフトを放置するコスト」が一気に表に出た例。
  https://www.php.net/archive/2026.php#2026-10-21-5

- **Google と Meta が TorchTPU を公開。PyTorch のコードがそのまま TPU で動く**（10/21）
  機械学習の定番ライブラリ PyTorch を、Google 独自の AI チップ TPU 上で「ほぼ 1 行の変更」で動かせる仕組みがオープンソースになった。PyTorch Conference 2026 での発表。
  これまで TPU を使うには専用の書き換えが必要だった。GPU（NVIDIA）だけに頼らなくても学習・推論ができる選択肢が増える、という話。
  https://cloud.google.com/blog/topics/ai-infrastructure/torchtpu-is-now-open-source-run-native-pytorch-on-tpus

- **Google Cloud の API Gateway が「ストリーミング」に対応（プレビュー）**（10/22）
  API の入り口となる Gateway で、SSE・WebSocket・gRPC といった「結果を少しずつ流す」通信を扱えるようになった。API の仕様書は変えなくてよい。
  AI の返答を 1 文字ずつ表示する画面や、エージェントの進捗表示は、こうしたストリーミングが前提。認証やログを共通化したまま AI 向け API を置ける。
  https://developers.googleblog.com/streaming-comes-to-api-gateway-real-time-and-ai-ready-apis-without-changing-your-spec/
