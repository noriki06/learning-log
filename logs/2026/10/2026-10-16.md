## 今日学んだこと

> 画面を API につなぐときは、**読む側 → 編集 → 新規登録の順に、1 つずつコミットを切る。**
>
> 管理画面の一覧・詳細・登録をまとめて API につないだ。まず一覧を本物のデータで出して、
> 検索の選択肢も API から取るようにし、次に詳細の編集、最後に一覧からの新規登録、と 3 回に
> 分けて入れた。読む側が先に動いていると、編集や登録の結果をすぐ画面で確かめられる。
>
> 書き込みの機能は、読み取りが先にできていてこそ確かめられる。読む → 書く の順で刻む。
