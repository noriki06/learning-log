## 今日学んだこと

> 画面で防いでいる確かめは、**API に直接送ると素通りする**。
>
> 生年月日の「今日より後は受け付けない」を API から外して画面任せにした。画面はプルダウンで未来の日付を出さないから大丈夫、のつもりだったけど、レビューで API に直接送ってみたら 2030 年の生年月日がそのまま保存された。答え直しも、画面に入口が無いだけで API は毎回上書きしていた。
>
> 画面は「普通の使い方」を絞る場所で、データを守るのは API の仕事。画面が止めるから API では省く、という省き方はしない。

## つまずき

- 生年月日の入力に、共通部品のカレンダーを使うと決めて作った。でも自分で触ってみたら、年を 1 つずつしか動かせなくて、30 年前の日付にたどり着くのが大変。結局、年・月・日のプルダウンに作り直した。
  部品の見た目や共通化より先に、実際に入れる値でひと通り操作してみる。次からは決める前に自分で触る。

- スマホの幅でプルダウン 3 つが 1 行に収まらず、数字も切れて、直すのに 2 回かかった。次からは幅を変えて確かめてからコミットする。
